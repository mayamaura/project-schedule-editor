プロジェクトスケジュールエディタ

複数プロジェクトの日程を「1プロジェクト = 1行」で俯瞰・編集するデスクトップアプリ。日程データは専用 Git リポジトリで管理し、Git に不慣れな人でも扱える UI を備える。

文書ステータス: ドラフト v0.1（2026-11-07）。各ページの「追記欄」に要件を書き足してから実装に入る想定。

目的

  • 縦軸=プロジェクト、横軸=日付の Excel ライクな画面で、日程を閲覧・編集できる（「Excel 風」は見た目のみ。操作は Excel と異なる）。
  • 1行（1プロジェクト）に複数の「イベント（開始〜終了）」と「マイルストーン（日付）」を載せられる。
  • プロジェクトの階層（親子）と、プロジェクト間（またはイベント間）の依存関係を扱い、表示対象・依存線の表示を切り替えられる。
  • データは Git で履歴管理。Git の用語を知らなくても「保存・共有・戻す」ができる。
  • 標準日程（ひな形）を複数保存し、プロジェクト追加時に、起点マイルストーンから日程を展開できる。
  • AI（GitHub Copilot SDK）に、日程の編集提案・評価・矛盾の指摘を依頼できる（AI は提案のみ、適用は人が承認）。

WBS との違い

一般的な WBS / ガント本アプリ
行の単位1行 = 1タスク1行 = 1プロジェクト（複数イベント・マイルストーン）
主な用途タスク分解・進捗管理複数プロジェクトの日程俯瞰・調整
依存関係タスク間プロジェクト間 / イベント間（要確認）
