4. 表示ルール

  • 色＋形＋ラベルで種別を示し、色覚に依存しない。イベント・マイルストーンの表示方法は選択可能（F-102）: イベント=バー/角丸バー/細線＋端点/背景帯/枠線/ストライプ、マイルストーン=◆/●/▲/■/★/旗/ラベルのみ。種別マスタで既定を設定し、項目ごとに上書きできる。
  • ラベルがバーに収まらない場合は外側に表示し、他要素と重ならないよう配置。
  • 依存線は直交ルーティング（直角折れ線）。交差を減らすため行間を優先して通す。
  • 祝日・週末は薄い背景、今日は縦線。「カレンダー」（ヘッダ）で、日本の祝日の有無・休みの曜日・会社の休日・特別稼働日を設定できる（祝日の一覧で確認できる）。背景と、標準日程の稼働日の計算に使う（実装済み）。
  • 編集の直後に、その変更で新たに生じた指摘（依存違反など）を画面上部に出す（編集は止めない。F-512）。履歴に残す前の確認にも「新たに見つかった不整合」を出す。
  • ダーク/ライトテーマ対応（OS設定追従）。

  • タイムライン風のプレビューで、起点マイルストーンの切替を試せる（展開ダイアログのプレビューは一覧で実装済み）。
  • 「標準日程として保存」（F-806）は、既存プロジェクトから起点マイルストーンを選んで作成する。
出力（R3。実装済み）: ヘッダの「出力」で、形式（HTML・PDF・PNG・SVG）・範囲（全体 / 選択中のプロジェクト / 表示中のビュー）・期間・依存線・日付ヘッダを選んで保存する。HTML ではメモ・担当者を含めるかを選べ（既定は含めない）、暗号化されない旨を出力前に表示する。出力した HTML は、アプリと同じズーム・スクロール・ツリーの開閉・依存線の切替・ホバーの詳細ができる閲覧専用ビューア（編集なし・外部通信なし）。詳細は architecture 16。
AI パネル（R4。実装済み。接続先は未接続）: ヘッダの「AI」で、画面を塞がない右側のパネルが開く（待機中も編集できる）。範囲（全体 / 選択中のプロジェクト / 表示中のビュー）とメモ・担当者の有無を選び、「送信内容を確認」で、AI に渡る内容そのものを見られる。依頼（チャット）・「評価する」・「矛盾をチェック」ができ、応答はストリーミングで流れ、中止できる。提案は差分（変更一覧）で確認して「承認して適用」（Undo 1 回で戻る）か「破棄」。変更が多い提案（既定 20 件超）は、確認のチェックが要る。指摘は「確定ではない」旨つきで並び、該当項目へジャンプできる。「指示・観点」はプリセット + 個人用 + チーム共有（共有は「履歴に残す」対象）で、編集できる。設定（有効/無効・モデル・件数の警告）とログ（ローカルのみ・削除可）もここにある。AI を使えないときは、理由が出て AI だけが無効になる。
