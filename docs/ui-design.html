3. 表示切替

機能内容
表示プロジェクトツリーのチェックボックスで表示/非表示。親を外すと子も非表示（個別に上書き可）
依存線全て / 選択中のみ / 上流のみ / 下流のみ / 非表示。種別・階層をまたぐもののみ、など
折りたたみレベル指定で一括展開（「第2階層まで」）
ビュー上記設定を名前付きで保存。共有/個人
差分モード履歴の2版を重ねて、変更された日程を色分け（旧=灰色の影、新=通常）。追加=緑、削除=打消し線、日付変更=旧位置から新位置への矢印と「+14日」表示。右パネルに変更一覧（クリックで該当行へジャンプ）。詳細は データモデル 4.5
変更サマリー保存・共有・履歴の各ダイアログで、変更を「プロジェクト名: 項目 旧→新」の文で一覧表示

4. 表示ルール

  • 色＋形（バー形状・◆●▲）＋ラベルで種別を示し、色覚に依存しない。
  • ラベルがバーに収まらない場合は外側に表示し、他要素と重ならないよう配置。
  • 依存線は直交ルーティング（直角折れ線）。交差を減らすため行間を優先して通す。
  • 祝日・週末は薄い背景、今日は縦線。
  • ダーク/ライトテーマ対応（OS設定追従）。
