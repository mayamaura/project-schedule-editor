要件定義

優先度: M=必須(MVP) / S=重要(次段階) / C=任意。依頼文から読み取れたものに加え、必要と思われるものを「提案」として記載（要判断）。

ID要件優先備考
F-101左に プロジェクトツリー（名称・列）、右に 日付軸のタイムラインを持つ Excel ライクな2ペイン表示M縦横スクロール同期、ヘッダ固定

F-512変更による依存違反の新規発生を警告として表示SF-305 と連動
F-506競合解決UI（項目単位で「自分の/相手の」を選ぶ）M最大のUX課題
F-507ブランチ相当の「シナリオ（案）」機能: 別案を作って比較・採用C用語は「案」。後回し可
F-508GitHub 認証の設定支援（Device Flow / PAT）Mリモートは GitHub（A5）。トークンは OS 資格情報ストアに保存

2. 非機能要件

ID要件目標（案）
NF-001性能（最大規模）500プロジェクト × 50イベント（約25,000件）× 8年。スクロール/ズーム 60fps 目標、ドラッグ中の遅延 <16ms、起動時の全データ読込 数秒以内
NF-002対応OSWindows 10/11。将来 macOS / Linux を追加できるよう、OS依存API・パス区切り・改行(LF固定)・資格情報保管（Electron safeStorage 等）を抽象化
NF-003オフライン編集・commit はオフライン可。共有時のみネット必要
NF-004データ安全性クラッシュ時も未保存編集を復元（自動一時保存）。Git操作は破壊的操作（force push, reset --hard）を提供しない
NF-005マージしやすさ同時編集の衝突が最小になるデータ形式（データモデル）
NF-006スキーマ互換スキーマバージョン付き。旧版データの自動マイグレーション。新しいデータを旧アプリが壊さない
NF-007セキュリティElectron: contextIsolation 有効、nodeIntegration 無効、preload 経由のIPCのみ。認証情報は OS 資格情報ストア
NF-008配布インストーラ(NSIS等)、コード署名、自動更新（要判断）。Git同梱によりユーザーに Git インストール不要
NF-009国際化日本語UI優先。文言は外出し（将来の多言語化余地）
NF-010アクセシビリティキーボードのみで主要操作可能。色だけに依存しない表示（形・パターン）
NF-011テストドメインロジック（日付計算・依存検証・差分）は単体テスト必須。E2E は主要フローのみ
非機能要件の追記。
