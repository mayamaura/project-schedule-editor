要件定義

優先度: M=必須(MVP) / S=重要(次段階) / C=任意。依頼文から読み取れたものに加え、必要と思われるものを「提案」として記載（要判断）。

1.7 AI アシスタント（GitHub Copilot SDK）

日程の編集依頼・評価・矛盾指摘を AI に依頼する機能。AI は日程を直接書き換えず、「提案」を生成するだけとし、適用は常に人が承認する。詳細は アーキテクチャ 6。優先度は暫定で S（MVP 後）。MVP に含めるかは要判断（E7）。

ID要件優先備考
F-701AI チャットパネル: 自然言語で日程の編集・評価・指摘を依頼できる（例:「設計フェーズを2週間延ばしたら、後続はどうなる？」）SGitHub Copilot SDK を使用
F-702AI による日程編集は「提案（変更セット）」として生成し、直接書き込まない。提案は diffSchedule と同じ差分表示で確認でき、承認 / 却下 / 変更単位の部分採用ができる。承認後は通常の編集コマンドとして適用（Undo 1単位）SF-509 と共通の差分表示を再利用。承認なしの自動適用は不可（E3）
F-703日程の評価: 観点（余裕・工程の妥当性・並行度・祝日/年末年始の影響 など）を指定または自由記述で依頼し、要約と根拠付きで結果を得るS評価の深さは保持データ（担当・工数の有無）に依存（E5）
F-704整合性チェック（ルールベース、AI 不要）: 依存違反、循環依存、終了<開始、子の期間が親の期間を逸脱、同一項目の重複 などを検出し問題一覧に表示するSvalidateSchedule（純関数）。F-305 を包含。結果は AI にも入力として渡す
F-705AI による矛盾・不成立の指摘: ルールで検出できない意味的な問題（名称・メモ・状態と日付の食い違い、非現実的な期間、依存の抜け漏れの疑い 等）を指摘する。F-704 の結果と重複して指摘しないS確定的な判定ではなく「指摘・疑い」として表示する
F-706AI の提案・評価・指摘の各項目は、該当するプロジェクト/イベント/マイルストーンへのリンクを持ち、クリックで該当行へジャンプ・ハイライトするS
F-707AI に渡すデータ範囲（選択項目 / 表示中のビュー / 全体）を選べ、送信前に内容をプレビュー・確認できるS外部送信のため。既定は最小範囲（E2）
F-708Copilot の認証（GitHub ログイン）と、AI 機能の有効/無効の個人設定。未認証・未契約・オフライン時は AI 機能のみ無効になり、他機能に影響しないSF-508 と認証基盤を共通化できるか要検証
F-709一度に適用する変更件数が多い提案（例: 20件超）は警告し、再確認を求めるS閾値は設定可能
F-710会話履歴・提案ログはローカルに保存し（Git 管理外）、利用者が削除できるS共有しない（E6）
F-711AI 提案を適用して保存する際、保存メモに「AI提案」と要約を自動付記するC履歴で AI 由来の変更を判別するため
F-712依頼文・評価観点のテンプレート（例:「リリース前のリスク確認」）の登録と利用C
機能要件の追記。

2. 非機能要件

ID要件目標（案）
NF-001性能（最大規模）500プロジェクト × 50イベント（約25,000件）× 8年。スクロール/ズーム 60fps 目標、ドラッグ中の遅延 <16ms、起動時の全データ読込 数秒以内
NF-002対応OSWindows 10/11。将来 macOS / Linux を追加できるよう、OS依存API・パス区切り・改行(LF固定)・資格情報保管（Electron safeStorage 等）を抽象化
NF-003オフライン編集・commit はオフライン可。共有時のみネット必要
NF-004データ安全性クラッシュ時も未保存編集を復元（自動一時保存）。Git操作は破壊的操作（force push, reset --hard）を提供しない
NF-005マージしやすさ同時編集の衝突が最小になるデータ形式（データモデル）
NF-006スキーマ互換スキーマバージョン付き。旧版データの自動マイグレーション。新しいデータを旧アプリが壊さない
NF-007セキュリティElectron: contextIsolation 有効、nodeIntegration 無効、preload 経由のIPCのみ。認証情報は OS 資格情報ストア
NF-008配布インストーラ(NSIS等)、コード署名、自動更新（要判断）。Git同梱によりユーザーに Git インストール不要
NF-009国際化日本語UI優先。文言は外出し（将来の多言語化余地）
NF-010アクセシビリティキーボードのみで主要操作可能。色だけに依存しない表示（形・パターン）
NF-011テストドメインロジック（日付計算・依存検証・差分）は単体テスト必須。E2E は主要フローのみ
NF-012AI のセキュリティAI に公開するツールは「読み取り」と「提案の作成」のみ（書き込み・ファイル・シェル系は公開/許可しない）。プロジェクト名・メモ内の文章に埋め込まれた指示には従わない（プロンプトインジェクション対策）。提案は必ず zod 検証を通す
NF-013AI の応答性非同期・ストリーミング表示・キャンセル可能。待機中も他の編集操作を妨げない
NF-014SDK の変更耐性Copilot SDK は技術プレビューで破壊的変更の可能性があるため、利用箇所を src/main/ai/ に閉じ込め、差し替え可能にする
NF-015プライバシーAI への送信データは最小限とし、送信先は Copilot（または設定した BYOK 先）のみ。送信内容は利用者が確認できる（F-707）
