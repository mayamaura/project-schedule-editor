# 整合性監査

1. `node scripts/check-docs.mjs` と `node scripts/trace.mjs --report` を実行し、機械的に検出できる不整合を出す。
2. `doc-auditor` サブエージェントで、機械検査では見つからない意味的な矛盾（例: 決定済みの方針と食い違う記述、用語の揺れ、要件と UI 設計のずれ）を調べる。
3. `src/` がある場合は、必須(M)要件の実装状況と文書の記述（データ形式・IPC・操作仕様）がコードと一致するか確認する。
4. 結果を「error（要修正）/ 要確認（ユーザー判断）/ 軽微」に分けて報告。修正は `/spec-change` の手順で行い、ユーザー判断が要るものは質問する。
