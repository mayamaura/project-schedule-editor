# 技術検証の手順（引数: 検証テーマ）

1. **問いを1文で定義**し、合否基準を数値で決める（例: 25,000イベントでスクロール 55fps 以上）。architecture.html の「技術検証で確認する項目」と対応付ける。
2. コードは `spike/<テーマ>/` に置く。**本体（`src/`）に混ぜない**。依存は spike 内に閉じる。
3. 計測は再現可能にする（データ生成スクリプト、計測方法、環境を記録）。
4. **結果を architecture.html に反映**: 方式、数値、採用/不採用の理由。これが決定なら `/spec-change` の手順で他文書・changelog も更新。
5. 採用した方式の本実装は別途 `/implement-feature` で行う。spike のコードをそのまま移植しない。
6. 結論が出たら spike ディレクトリの扱い（残す/削除）をユーザーに確認する。
